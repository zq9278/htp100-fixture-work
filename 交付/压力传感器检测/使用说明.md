# HTP100 压力传感器检测软件

本目录对应 Git 分支 `压力传感器检测`。**上位机是现有 H7 屏幕板，使用 LVGL 驱动原屏幕；下位机是现有 G0 主板，使用 ADS1220 采集压力。** 两板独立运行即可测量和校准，无需 PC。Windows 程序保留为 G0 USART1 的辅助调试工具。原耗材软件保留在 `耗材初始化检测` 分支。

## 主板接线与烧录

两块板子沿用原来的屏幕连接，均为 115200、8N1：

| G0 下位机 | H7 上位机 |
| --- | --- |
| PA2 / USART2_TX | PA10 / USART1_RX |
| PA3 / USART2_RX | PA9 / USART1_TX |
| GND | GND |

G0 的 LCD_PW 保持原屏幕供电，充电时不关闭 H7。H7 使用原触摸、背光、LCD 时序及 QSPI BOOT 架构，屏幕类型按实物选择。

可选 PC 使用 **3.3V TTL USB 串口模块**，独立接到 G0 USART1：

| USB 串口模块 | 主板 |
| --- | --- |
| RX | PB6 / USART1_TX |
| TX | PB7 / USART1_RX |
| GND | GND |

主板按原设计供电，USB 串口模块只连接信号和共地。**PC 不接 PA2/PA3，也不接 H7 USART1**，不会与两板通信争用 TX。USART1 的调试文本日志已关闭，避免混入二进制协议。两路串口独立处理命令和回包，共享 G0 的同一采样／峰值状态；采样或捕捉忙时会拒绝冲突的变更。

安装 SEGGER J-Link，接对应板子的 SWDIO、SWCLK、GND、VTref，建议接 NRST。G0 使用 `Burn_Pressure_Main.bat`；H7 使用 `Burn_Pressure_Screen.bat`，输入 1 选择新屏、2 选择旧屏。两块板子都需烧录本目录的新固件。H7 只更新 `0x90000000` 的 QSPI 应用，保留原内部 BOOT；空白 H7 板需先另行装入原 BOOT。

仅检查文件及命令、不连接探针：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\flash_pressure.ps1 -Board Main -FirmwarePath .\HTP100-Pressure-Monitor.hex -DryRun
powershell -NoProfile -ExecutionPolicy Bypass -File .\flash_pressure.ps1 -Board Screen -ScreenVariant New -DryRun
powershell -NoProfile -ExecutionPolicy Bypass -File .\flash_pressure.ps1 -Board Screen -ScreenVariant Old -DryRun
```

脚本检查 HEX 校验和、地址范围和向量表，主板数据只能位于 `0x08000000～0x0801FFFF`；不执行整片擦除或选项字节修改。程序不自动连接串口或自动烧录。

## 实时压力和峰值

1. 两板上电，H7 自动连接 G0，屏幕显示连接、传感器和充电／电量状态。PC 为可选工具，需要时打开 EXE 并选择 G0 USART1 对应串口。
2. 日常测量前，移除新增载荷，点击“空载去皮”，保持静止 1 秒。未校准时使用原项目的名义灵敏度估算并明确标记；未建立零点前只提供 ADC 原始数据。
3. 大字显示滤波后的 mmHg，下方同时显示对应的**牛顿力 N 和等效克数 g**，以及未滤波瞬时压力和 ADC 原码。三种单位使用同一帧测量值与有效面积换算，保留负数便于观察零点漂移。峰值区域也同时显示 mmHg、N、g。
4. 输入捕捉时长（0.1～3600 秒），点击“开始捕捉”。下位机在 `[开始时刻, 开始时刻+时长)` 内比较每个采集到的有效读数，锁存最大值、最小值、峰值时刻和样本数。
5. 时间到后 H7 提示完成并鸣响，结果保持，也可“提前结束”保留部分结果。下一次捕捉或修改校准／去皮会清除本次设备结果。PC 工具额外支持历史结果和 CSV 导出；H7 主要显示当前一次结果和最近压力曲线，不使用文件存储。

峰值取**未滤波采样值**，不会因 PC 曲线刷新漏掉下位机已经采集的峰值。ADS1220 保留原配置：AIN1/AIN2、PGA 128、AVDD 参考、正常模式标称 330 SPS。串口使用 DMA 队列，充电／电量轮询在低优先级任务中运行，避免阻塞采样。实际采集率受任务调度和 SPI 访问影响，低于 ADC 标称上限；用“有效样本数 ÷ 捕捉时长”可查看该次平均采集率。两次采样之间的极短模拟脉冲不保证捕获，ADC 硬件滤波也影响瞬态峰值。

H7 触摸时长、使用量程、允许误差或面积字段可弹出数字键盘，点勾号确认关闭。实时大字使用显示滤波，峰值和瞬时值不滤波。H7 曲线约显示最近 20 秒（界面 10Hz、200 点），PC 曲线显示最近 60 秒。

断线、通信失败、ADC 饱和不会伪装成 0 mmHg；异常计入设备结果并提示不完整。数据过期时实时值失效，H7 通讯超时会自动重新握手；不会自动重放去皮、保存或开始命令。H7 或 PC 断线／重启后，G0 已启动的捕捉继续，重连可读回当前状态。模拟信号断线不一定呈现 ADC 饱和，需结合实物接线确认。

## 用砝码校准

该传感器测量的是**力**，mmHg 是结合指定受力面积换算的**等效压力**。换算关系为：

```text
质量(g) = (ADC 原码 - 零点原码) × 灵敏度(g/count)
压力(mmHg) = 质量(g) × 9.80665 × 1000 ÷ 有效受力面积(mm²) ÷ 133.3224
力值(N) = 压力(mmHg) × 133.3224 × 有效受力面积(mm²) × 10⁻⁶
等效克数(g) = 力值(N) × 1000 ÷ 9.80665
```

面积先沿用项目现值 **84.8 mm²**，应按最终夹具／压头的实际有效受力面积确认。按此面积，100 g 约为 **86.740 mmHg**，300 g 约为 **260.221 mmHg**，500 g 对应约 **433.702 mmHg / 4.903 N / 500.0 g**。这里的克数是按标准重力换算的等效质量。实时三种单位同步使用显示滤波；峰值三种单位都对应未滤波锁存峰值。砝码校准不能单独证明机械结构的有效面积正确。

H7 采用引导式流程。使用范围以 **0～500 g** 为例，实际填写值必须在传感器与夹具的额定载荷内：

1. 按最终使用方向固定传感器、压头和加载盘，保持居中、轴向受力。进入“砝码校准”，填写**使用量程、允许误差 g、换算面积 mm²**。量程支持 5～100000 g；这是校准覆盖范围，不是硬件额定载荷声明。允许误差默认随量程设为 0.5%，可按实际要求修改；该值只是复核门限，不代表已达到整机精度。
2. 点击“开始引导”。在额定范围内预加载、卸载三次，结构稳定后点击“预加载已完成”。预加载由操作者执行、确认，软件不会驱动电机。
3. 按屏幕提示依次采集 **0%、20%、40%、60%、80%、100%** 六个点。500 g 示例对应 **0、100、200、300、400、500 g**。0 g 时保留加载盘／压头、移除新增砝码；其他点放置提示的新增砝码总质量。每次等稳定后点击“稳定后采集”，G0 采样 1 秒；使用 ADC 均值，排除放砝码时的冲击峰值。
4. 六点完成后自动计算线性最小二乘拟合，求出零点与带符号灵敏度；允许接线极性相反。表格显示“前差 g”和“后差 g”，均为测量值减标准值。前差使用进入流程时的原设备参数；原来没有零点时显示 `--`。后差是拟合后的结果。拟合最大克数残差必须在填写的允许误差内，判定不依赖面积；采样不足、ADC 变化不足、噪声过大或异常拟合会被拒绝。
5. 点击“应用并复核”。H7 检查 G0 参数回读一致后开始独立复核，参数此时只在 RAM 中，**不会自动保存到 EEPROM**。
6. 按提示完成 **三轮加载、卸载复核**。每轮为 **0、100、200、300、400、500、400、300、200、100、0 g**，每级重新静置、采集 1 秒，共 33 个新采样窗口。复核数据不参与重新拟合；期间不要去皮，否则会掩盖回零误差。屏幕同时给出目标克数与对应 N。
7. 屏幕显示最大示值误差、重复性、迟滞和回零误差。**四项都不超过允许误差，才启用“保存参数”**。失败时保存按钮禁用，可以“重测”重新进行三轮复核，或“结束”后重新校准；检查偏载、摩擦、结构迟滞和砝码是否放置正确。
8. 合格后点击“保存参数”，回读成功显示“复核通过，参数已保存”。参数断电保留；重启后再用已知砝码检查实时值和空载回零。可另外用未参与标定的中间重量检查插值误差。

指标计算均以 g 为单位：

| 指标 | 计算方式 |
| --- | --- |
| 最大示值误差 | 33 次复核中 `abs(测量值－标准值)` 的最大值 |
| 重复性 | 同一载荷、同一加载方向在三轮间的最大值减最小值，再取各级最大值 |
| 迟滞 | 每轮相同载荷的加载值与卸载值之差的绝对值，再取最大值；包含起始与终止空载比较 |
| 回零误差 | 每轮卸载到 0 g 后的示值绝对值，取三轮最大值 |

表格可滚动，包含六个标定点和十一种复核阶段；复核表中的前差／后差为已完成各轮的平均误差。整体“最大差”仍使用每一次复核误差，平均不会掩盖单次超限。上述门限和流程用于设备自校与复核，不等同于取得计量机构证书。本版按当前压向安装结构操作，不包含拉／压两套独立系数。

引导期间锁定参数输入、去皮和开始峰值功能。两板断线、命令超时，或读取到其他接口修改的校准参数时，中断流程；重连后重新开始。不要让 PC 与 H7 同时修改参数。点击“返回”只切换到实时页，流程仍保留；点击“结束”退出流程，已应用的 RAM 参数不会自动撤销，原 EEPROM 记录不会因未保存的流程而被覆盖。

日常去皮只改变零点，不修改灵敏度；H7 日常去皮不会自动保存。重新上电会恢复上次已保存的校准。更换传感器或调整加载结构后重新标定；修改有效面积后复核 mmHg 换算。

PC 保留自由采点的辅助调试页，最多八点，建议覆盖上述六级；完整三轮复核与保存门限在 H7 引导中实现。PC 原自由拟合仍使用 `max(2 mmHg, 标定跨度的0.5%)` 残差门限；PC 的应用／保存属于直接调试操作。PC 可导出校准 JSON 留档，不自动导入其他设备。H7 的标定与复核明细仅保存在本次运行的 RAM 中，重启后不保留；EEPROM 只保存最终零点、灵敏度和面积。

## 参数保存与充电

- 主板外置 EEPROM 使用 `0x90～0xAF` 和 `0xB0～0xCF` 两个独立 32 字节校准记录，包含版本、递增序号、零点、灵敏度、面积及 CRC16。
- 保存只改非当前槽，先失效标记、后写数据、最后提交标记并回读。写失败时上一个有效校准仍可使用；两槽均无效时明确回到未校准状态。正常开机不擦除 EEPROM，不执行原产品的初始化／计数操作。
- 原 BQ25895 5V／2A 输入配置、约 1.984A 充电设置、4.208V 电压设置及 BQ27441 电量读取保留。本版允许边充电边测量；充电电路按现有硬件工作。
- H7 和 PC 均显示外部供电／充满、电量和电池电压。电量计读取失败时显示未知，不沿用陈旧值。G0 保持 H7 供电，充电时可继续测量。
- 加热 PWM 关闭，电机 ENN 保持禁止；本版没有治疗、耗材写入、自动加热或电机运动命令。

## 记录、源码和验证范围

PC 的“开始记录 CSV”持续写入遥测，包含电脑时间、设备时刻、原码、瞬时／滤波压力、峰值、样本数、异常、状态位和校准参数。不限制 CSV 记录时长，掉线或关闭程序会关闭文件。

CSV 同时包含瞬时、滤波和峰值对应的 N、g；峰值结果表和结果导出也增加峰值力和峰值克数。为保证三单位一致，当前遥测随帧附带有效面积。请同时更新 G0、H7 及 PC 程序；若只接到旧的 52 字节遥测固件，保留 mmHg 显示，N／g 显示为未知，需更新 G0。

使用 H7 修改校准参数后，在 PC 点击“读取设备参数”，再开始新的 CSV 记录，使记录中的校准参数与 G0 当前值一致。

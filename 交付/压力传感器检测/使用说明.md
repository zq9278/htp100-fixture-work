# HTP100 压力传感器检测软件

本目录对应 Git 分支 `压力传感器检测`。上位机为 Windows 程序，下位机用于现有 STM32G070CB 主板和 ADS1220 采集接口。原耗材检测软件保留在 `耗材初始化检测` 分支。

## 文件与启动

| 文件 | 用途 |
| --- | --- |
| `HTP100_Pressure_Sensor_Host.exe` | Windows 上位机，直接双击，无需安装 Python |
| `HTP100-Pressure-Monitor.hex` | 主板烧录文件 |
| 同名 `.bin` / `.elf` | 原始镜像 / 调试镜像 |
| `Burn_Pressure_Main.bat` | J-Link 主板烧录入口 |
| `flash_pressure.ps1` | 烧录脚本，需与 BAT、HEX 一起保留 |
| `上位机界面（仿真数据）.png` | 仿真联调界面示例，不是实测数据 |

## 主板接线与烧录

使用 **3.3V TTL USB 串口模块**：

| USB 串口模块 | 主板 |
| --- | --- |
| RX | PA2 / USART2_TX |
| TX | PA3 / USART2_RX |
| GND | GND |

主板按原设计供电，USB 串口模块只连接信号和共地；串口为 **115200、8N1**。本版 PC 使用原屏幕串口，主板启动后关闭 LCD 供电。接入 PC 时断开原屏幕的串口信号，避免两路 TX 输出并联及未上电屏幕被信号反向供电。本任务无需烧录屏幕板。

J-Link 接主板 SWDIO、SWCLK、GND、VTref，建议接 NRST。安装 SEGGER J-Link 后，双击 `Burn_Pressure_Main.bat` 烧录、校验并复位。只烧录本目录中的压力检测固件，不使用上一层的耗材检测烧录入口。

仅检查文件及命令、不连接探针：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\flash_pressure.ps1 -Board Main -FirmwarePath .\HTP100-Pressure-Monitor.hex -DryRun
```

脚本检查 HEX 校验和、地址范围和向量表，主板数据只能位于 `0x08000000～0x0801FFFF`；不执行整片擦除或选项字节修改。程序不自动连接串口或自动烧录。

## 实时压力和峰值

1. 打开 EXE，选择主板所在串口，点击“连接设备”。程序检查压力检测固件版本。
2. 日常测量前，移除新增载荷，点击“空载去皮”，保持静止 1 秒。未校准时使用原项目的名义灵敏度估算并明确标记；未建立零点前只提供 ADC 原始数据。
3. 左侧大字显示滤波后的 mmHg，下面同时显示未滤波瞬时值和 ADC 原码。保留负数，便于观察零点漂移。
4. 输入捕捉时长（0.1～3600 秒），点击“开始捕捉”。下位机在 `[开始时刻, 开始时刻+时长)` 内比较每个采集到的有效读数，锁存最大值、最小值、峰值时刻和样本数。
5. 时间到后结果保留，也可“提前结束”保留部分结果。下一次捕捉或修改校准／去皮会清除本次设备结果；上位机已接收的历史结果保留，可导出 CSV。

峰值取**未滤波采样值**，不会因 PC 曲线刷新漏掉下位机已经采集的峰值。ADS1220 保留原配置：AIN1/AIN2、PGA 128、AVDD 参考、正常模式标称 330 SPS。串口使用 DMA 队列，充电／电量轮询在低优先级任务中运行，避免阻塞采样。实际采集率受任务调度和 SPI 访问影响，低于 ADC 标称上限；用“有效样本数 ÷ 捕捉时长”可查看该次平均采集率。两次采样之间的极短模拟脉冲不保证捕获，ADC 硬件滤波也影响瞬态峰值。

断线、通信失败、ADC 饱和不会伪装成 0 mmHg；传感器异常计入设备结果并提示不完整。通信长时间无更新时实时值显示失效。PC 断线后下位机捕捉继续，重新连接会读取当前状态。模拟信号断线不一定呈现 ADC 饱和，需要结合实际桥式传感器接线进行台架确认。

## 用砝码校准

该传感器测量的是**力**，mmHg 是结合指定受力面积换算的**等效压力**。换算关系为：

```text
质量(g) = (ADC 原码 - 零点原码) × 灵敏度(g/count)
压力(mmHg) = 质量(g) × 9.80665 × 1000 ÷ 有效受力面积(mm²) ÷ 133.3224
```

面积先沿用项目现值 **84.8 mm²**，应按最终夹具／压头的实际有效受力面积确认。按此面积，100 g 约为 **86.740 mmHg**，300 g 约为 **260.221 mmHg**，500 g 约为 **433.702 mmHg**。砝码校准能确定力与 ADC 的关系，不能单独证明机械结构的有效面积正确。

操作步骤：

1. 按最终使用方向装好传感器和加载结构，保持居中、垂直加载。砝码重量按传感器实际额定量程选择；以下 0 / 100 / 300 / 500 g 仅作为操作示例。
2. 在“砝码校准”填写有效受力面积。保留加载盘／压头，去除新增砝码，填写 **0 g**，静置后点击“采集校准点”。每个点采样 1 秒，返回 ADC 均值、标准差和样本数。
3. 放上已知砝码，输入**新增砝码的总质量**，静置后再次采集。依次覆盖实际工作范围；至少空载加一个非零点，推荐三个以上点，并补充卸载复测。
4. 点击“计算校准”。程序进行线性最小二乘拟合，显示零点、带符号灵敏度、RMS 和逐点压力残差；正反接线极性均可处理。重量跨度过小、噪声过大、读数不一致或异常参数会被拒绝。
5. 点击“应用校准到设备 RAM”。设备回读一致后开始使用新参数；此时尚未断电保存。
6. 使用**未参与拟合的砝码**复核，例如 200 g；加载和卸载分别验证零点、重复性与迟滞。软件内部拟合残差门限为 `max(2 mmHg, 标定跨度的 0.5%)`，它用于排除不一致采样，不代表整机精度规格。最终允许误差应由实际测量要求确定。
7. 复核合格后点击“保存设备参数（断电保留）”，显示成功后再重启回读检查。

两点只能求斜率和零点，无法识别非线性；多点残差和独立砝码复核都需要做。日常去皮只改变零点，不修改已校准的灵敏度；去皮结果只有在“保存设备参数”后才会断电保留。更换传感器、调整加载结构或改变有效面积后，重新采集并复核。

上位机可导出校准 JSON，包含砝码点、均值、噪声、拟合结果、面积和设备参数；此版本的 JSON 用于留档，不自动导入或写入其他设备。

## 参数保存与充电

- 主板外置 EEPROM 使用 `0x90～0xAF` 和 `0xB0～0xCF` 两个独立 32 字节校准记录，包含版本、递增序号、零点、灵敏度、面积及 CRC16。
- 保存只改非当前槽，先失效标记、后写数据、最后提交标记并回读。写失败时上一个有效校准仍可使用；两槽均无效时明确回到未校准状态。正常开机不擦除 EEPROM，不执行原产品的初始化／计数操作。
- 原 BQ25895 5V／2A 输入配置、约 1.984A 充电设置、4.208V 电压设置及 BQ27441 电量读取保留。本版允许边充电边测量；充电电路按现有硬件工作。
- 上位机显示外部供电／充满、电量和电池电压。电量计读取失败时电量、电压显示未知，不沿用陈旧值。
- 加热 PWM 关闭，电机 ENN 保持禁止；本版没有治疗、耗材写入、自动加热或电机运动命令。

## 记录、源码和验证范围

“开始记录 CSV”持续写入遥测，包含电脑时间、设备毫秒时刻、原码、瞬时／滤波压力、峰值、样本数、异常次数、状态位和当前校准参数。界面曲线只保留最近 60 秒，不限制 CSV 持续记录时长。掉线或关闭程序会关闭文件。

HTP100 pressure sensor monitor - verification record
Date: 2026-10-24 (Asia/Shanghai)
Branch: 压力传感器检测

PASS: Release firmware built with ARM GCC 14.3.1 / CMake / Ninja.
      G0 FLASH 58776 bytes; static RAM and reserved heap/stack 23384 bytes.
      H7 new-panel FLASH 702940 bytes; old-panel FLASH 702964 bytes.
      H7 DTCM RAM 22232 bytes; AXI DMA buffer 256 bytes; LVGL uses existing SDRAM.
      Charger/gauge task stack is allocated from the existing FreeRTOS heap.
PASS: Production ARM measurement engine tests; 119 wire frames decoded by PC parser.
      Pressure conversion, instantaneous-vs-filtered display, calibration reset,
      peak/deadline, abort, busy locks, stale/saturation, stable/noisy tare,
      point capture, stream recovery, duplicate commands, EEPROM save,
      interrupted-write rollback, corrupt-slot fallback, timer/generation wrap.
PASS: Production UART DMA queue under ARM emulation with a fake HAL.
      Copy lifetime, order, circular wrap, overflow rejection, timeout recovery.
      Independent USART1 PC interrupt RX/TX, buffer overflow and RX recovery.
PASS: Production H7 client and G0 core tested together on ARM.
      Discovery, four-point mass fit, apply/save/readback, peak, H7 reboot,
      reconnect, and independent H7/PC response routing, sequence caches and locks.
PASS: Actual new/old H7 LVGL ELF rendering linked to the real G0 simulator.
      Touch buttons, tare, 4 mass points, compute/apply/save/readback,
      numeric keyboard READY, persistent input validation, peak display,
      stale pressure/power values and disconnection.
PASS: 10 pytest cases including real Qt PC GUI to production ARM C USART1 channel.
      Four-point mass calibration, RAM apply/readback, EEPROM save/reboot,
      5ms sampled peak between telemetry frames, stale display and reconnection.
PASS: Windows EXE built with PyInstaller 6.22.3, startup smoke check (offscreen).
PASS: All 3 HEX checksum/address/vector validations and J-Link command DryRuns.
      The H7 programmer rejects a G0 image before any probe connection.
PASS: ELF inspection excludes eye EEPROM/treatment/heater/motor runtime.

Runtime dependencies packaged: Python 3.12.10, PyQt5 5.15.11, pyserial 3.5.
Calibration reference: masses + effective area; default area 84.8 mm^2.
H7 previews are under H7界面预览（仿真）; the PC preview is labeled simulated data.
H7 USART1 PA9/PA10 <-> G0 USART2 PA3/PA2; PC <-> G0 USART1 PB6/PB7.
Both links are independent 115200 8N1; the H7 stays powered during charging.

NOT PERFORMED: physical programming, real sensor mass calibration, actual-area
verification, sensor accuracy/hysteresis tests, charge/discharge bench tests.
No physical serial port or programming probe was opened by these checks.

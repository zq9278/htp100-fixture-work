# HTP100 综合工装使用说明

合并日期：2026-11-06。H7 为 LVGL 上位机，G0 为采样、耗材处理及加热控制下位机。主界面包含眼盾初始化、制作演示耗材、眼盾出厂检测、清除使用标记及新增的压力计。

## 烧录与接线

**G0 与 H7 都要更新成此目录的合并版固件。** 不要把原单功能分支的屏幕固件与本版主板混用。

| 文件 | 用途 |
| --- | --- |
| `Burn_Combined_Main.bat` | 烧录 G0 主板 |
| `Burn_Combined_Screen.bat` | 烧录 H7，输入 1 新屏／2 旧屏／Q 退出 |
| `flash_combined.ps1` | BAT 共用脚本，与 HEX 保存在同一目录 |
| `HTP100_Combined_Main.hex` | G0 固件 |
| `HTP100_Combined_Screen_New.hex` | H7 新屏固件 |
| `HTP100_Combined_Screen_Old.hex` | H7 旧屏固件 |
| 同名 `.bin` / `.elf` | 原始镜像与调试镜像 |
| `HTP100_Combined_PC.exe` | 可选 PC 压力辅助程序 |
| `界面预览（仿真）/` | 实际 H7 固件渲染的示例，包含新旧屏，不是实测数据 |

使用 J-Link，连接 SWDIO、SWCLK、GND、VTref，建议同时接 NRST。H7 只更新 QSPI 应用区 `0x90000000`，保留原内部 BOOT；空白屏幕板仍需原 BOOT。G0 不执行整片擦除或选项字节修改。

两板沿用原连接，115200、8N1：G0 PA2/USART2_TX → H7 PA10/USART1_RX，G0 PA3/USART2_RX ← H7 PA9/USART1_TX，并共地。可选 PC 用 3.3V TTL 串口接 G0 PB6/USART1_TX、PB7/USART1_RX 和 GND。PC 不与屏幕串口并联。

## 主界面及模式切换

原四个耗材功能沿用当前耗材分支实现，包括批量拔出后等待下一件、出厂检测连续 PID 控温、超温及断线保护、失败诊断，以及清除标记只操作耗材 `0x01～0x04` 并回读校验。

点击“压力计”立即打开压力页，右上角“主界面”立即返回眼盾菜单；未连接 G0 也可以浏览。底部提示“等待G0确认，仅浏览”或“G0未连接，仅浏览，连接后自动重试”，不会遮挡按钮。G0 确认关闭加热并切换模式后才允许压力操作；确认前不发送眼盾开始或压力操作命令。H7 重启默认进入眼盾菜单，并在后台请求 G0 关闭此前的耗材任务。

压力模式下，迟到的耗材开始命令不能重新开启加热；主界面或耗材模式下，PC／H7 的压力参数修改、去皮等变更会被拒绝。PC 调试前先在 H7 选择压力计。退出压力模式会取消仍在收集的压力校准／去皮窗口，防止切换后才改写零点。压力读数与充电状态仍可广播；耗材处理中的阻塞访问会影响后台压力采样，正式压力测量请进入压力计。

## 持续压力与峰值

建立零点后，G0 自动持续比较未滤波有效采样，保留最大值。实时值和峰值均同步显示 mmHg、N、等效克数 g。实时值使用 40ms 显示滤波；峰值直接比较原始有效采样，不因界面刷新错过已采到的峰值。

“清除峰值，重新捕捉”只清除本轮最大／最小值、计数和时间，从下一次有效采样继续比较，不改变实时值或校准。没有时长设置或自动结束。去皮、应用校准、极性反转也会清除旧峰值后重新累计。校准放置的砝码同样可能计入峰值，正式测量前清除即可。

ADC 饱和和无效样本不参与峰值比较，实时异常不会伪装成 0；原有效峰值保留。H7／PC 断开不会清除 G0 峰值，G0 重启重新累计。超过 uint32 计时／计数上限时饱和，峰值比较继续。两次采样之间的极短脉冲仍无法保证捕获。

## 极性反转与精度

当前安装方向加载后为负数时，点击“极性反转”。G0 将校准斜率乘以 -1，零点、斜率幅度、面积和采样设置保持不变；实时三单位与连续最大值都在 G0 中按新方向计算。反转后旧峰值清除，避免把两个方向的结果混在一起。校准引导或采样忙时先等待完成／退出。

极性先在 RAM 生效，复核后点击“保存参数”，已有完整校准的参数可断电保留。还未完成砝码校准时，先完成校准及保存。PC 也提供“极性反转”和原有保存参数功能。

**单纯改变符号不会增加数值误差。** 如果实际安装和受力方向改变，应重新去皮、按当前安装方向校准并复核重复性、迟滞和回零。拉向与压向的机械响应不能仅凭反转符号判断相同；厂家也按受力模式进行校准。[Interface 技术说明](https://www.interfaceforce.com/load-cell-test-protocols-and-calibrations/)

多点拟合本身支持正负斜率，按当前方向采集正质量砝码即可自动求出合适符号。零点附近的小负值保留，便于观察漂移。

## 砝码校准

1. 固定传感器、压头和加载盘，居中轴向加载。填写使用量程、允许误差 g、有效受力面积 mm²。量程不能超过传感器及夹具额定载荷；默认 500g 只是操作示例，允许误差默认量程 0.5%，可以自行修改，不代表已达到整机精度。
2. 点击“开始引导”，在允许范围内预加载、卸载三次，确认完成。保留加载盘，去除新增砝码，采集空载。
3. 按 0/20/40/60/80/100% 六点依次采集；500g 示例对应 0、100、200、300、400、500g。每级静置后采样 1 秒。
4. 六点自动计算零点和灵敏度，显示前后误差；点击“应用并复核”只应用到 RAM。
5. 三轮分别按 0→100→200→300→400→500→400→300→200→100→0g 加载／卸载，每级重新采集，期间不要去皮。复核数据不重新参与拟合。
6. 示值误差、重复性、迟滞、回零误差都不超过设定门限才允许保存；失败可重测或结束后重新校准。成功保存后重启，再用已知砝码和未参与拟合的中间重量复查。

面积仅影响等效压力换算，不影响力值拟合的克数门限。默认面积沿用 84.8mm²，需要按实际有效受力面积确认。换算为 `N=g×9.80665/1000`，`mmHg=N÷(面积mm²×10⁻⁶)÷133.3224`。

## 充电、数据及验证

保留 BQ25895 与 BQ27441 配置，允许边充电边测量，屏幕保持供电。电量计失败显示未知。电机初始化及运动仍禁用；加热仅由耗材出厂检测控制。

压力校准使用主板 EEPROM `0x90～0xCF` 双槽记录，和耗材的 I2C2 EEPROM 分开。开机不执行旧产品 EEPROM 初始化或擦除。原压力分支保存的校准记录仍可读取。校准明细和峰值不写 EEPROM；只保存最终零点、灵敏度和面积。

PC 提供实时 CSV、峰值界面快照和校准 JSON。不要同时从 H7 和 PC 修改参数；读取到外部参数变化时，H7 引导会中断。CSV 的遥测面积用于同帧三单位换算。

本版已通过生产 C 核心 ARM 仿真、实际 H7 LVGL ELF 渲染、耗材 EEPROM HAL 仿真、新旧屏编译及烧录文件 DryRun。**尚未连接实物烧录，实际受力精度、充电和板级切换仍需台架确认。**
